Action button — teal primary, 12px radius, 44px default height. One primary CTA per screen (v2 §23).

```jsx
<Button icon="search">Show activities</Button>
<Button variant="secondary" icon="sparkles">Let Scout guide me</Button>
<Button variant="ghost" iconRight="external-link" href={providerUrl}>Visit provider</Button>
```

Variants primary/secondary/ghost/danger; sizes sm/md/lg; `fullWidth` for mobile sheets. Calm sentence case, never shouty.
